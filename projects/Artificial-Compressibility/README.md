# Artificial Compressibility for Incompressible Flow (MATLAB)

**Status:** Archived MATLAB numerical-methods study; source files and the paper remain in the original `artificial_compressibility.zip` archive and are not included in this GitHub entry.

The archive includes `art_comp.m`, a MATLAB implementation experimenting with artificial-compressibility pressure updates and velocity equations for a two-dimensional rectangular channel, and `artificial_compressibility.mlx`, a MATLAB live script. The `.m` script uses a Cartesian mesh, a pseudo-time step, an artificial-compressibility parameter, Reynolds-number-based flow conditions, and velocity/pressure boundary conditions.

**Attribution:** The additional file `ac_method_laszlo_code.m` explicitly states that it was written by Dr Laszlo Konozsy at Cranfield University (28 January 2025), and is reference/teaching code, **not claimed as original author work**. The archive also includes `L_Könözsy_et_al_Variable_Density_Flow_ECCOMAS_Paper_2012.pdf`, a third-party research paper. Neither is republished here.

**Keywords:** MATLAB, Chorin artificial-compressibility method, incompressible Navier–Stokes, pseudo-time marching, rectangular channel flow, finite differences, pressure–velocity coupling.

**Disclosure:** Implementation completeness, stability, convergence, and analytical validation are not independently established from this archive. No numerical results are claimed here.
